# Final Paper (LaTeX)

This directory contains the final paper in a modular, LaTeX-first structure. The paper is
assembled from `main.tex`, which `\input{}`s one file per section from `sections/`, and
uses `references.bib` for all citations.

```
docs/final_paper/
├── main.tex
├── references.bib
├── README.md
├── EVIDENCE_MAP.md
├── sections/
│   ├── abstract.tex
│   ├── introduction.tex
│   ├── related_work.tex
│   ├── datasets.tex
│   ├── methodology.tex
│   ├── experimental_setup.tex
│   ├── results.tex
│   ├── discussion.tex
│   ├── threats_to_validity.tex
│   └── conclusion.tex
├── figures/
└── tables/
```

## Compiling the paper

A standard LaTeX distribution (TeX Live or MiKTeX) is required. From this directory run:

```bash
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

(`latexmk -pdf main` performs the same three passes automatically if `latexmk` is
installed.)

### Required packages

The document uses the `article` class (10pt, A4) and the following standard packages, all
of which ship with a full TeX Live/MiKTeX install:

- `fontenc`, `inputenc`, `lmodern`
- `amsmath`, `amssymb`
- `graphicx`
- `booktabs`
- `caption`
- `microtype`
- `geometry`
- `hyperref`

The bibliography uses the built-in `unsrt` BibTeX style (numeric citations in order of
first appearance, matching the IEEE-style `[1]`, `[2]`, ... numbering of the original
draft). No custom class or `.bst` file is required.

### Customization notes

- The `\author{}` block in `main.tex` is a placeholder and should be replaced with the
  actual author list and affiliation.
- The title mirrors the original milestone-1 draft title.

## Data-to-table / data-to-figure pipeline

No numerical result in the tables or figures is hand-entered. Every table and every data
figure is generated programmatically from validated project artifacts:

| Output | Generated by | Source artifacts |
|---|---|---|
| `tables/*.tex` | `scripts/final_paper/generate_tables.py` | CSV/JSON under `outputs/` and `docs/milestone_2/` (see `EVIDENCE_MAP.md`) |
| `figures/*.pdf` (data figures) | `scripts/final_paper/generate_figures.py` | CSV under `outputs/milestone_6/` and `outputs/milestone_7/` |
| `figures/pipeline.png` | copied from milestone 3 | `docs/milestone_3/Unified Preprocessing and Validation Pipeline remake.png` |
| `figures/partition_roles.png` | copied from milestone 3 | `docs/milestone_3/Experimental roles and leakage prevention remake.png` |

Regenerate all tables and figures after any change to the underlying results:

```bash
python scripts/final_paper/generate_tables.py
python scripts/final_paper/generate_figures.py
```

Then recompile the paper. The generation scripts read only the validated artifacts; they do
not duplicate or hard-code any numeric value. See `EVIDENCE_MAP.md` for the exact
source-file to table/figure mapping.

## Assumptions

- The three frozen partitions are KITTI train (5,985 images), KITTI validation (1,496
  images), and the Waymo external subset (996 images).
- The harmonized task is three-class Vehicle / Pedestrian / Cyclist.
- The frozen operating point is confidence >= 0.25 and IoU >= 0.50.
- The primary metric is COCO mAP@[0.50:0.95].
- All four detectors use the locked KITTI-trained checkpoints recorded in
  `outputs/milestone_4/manifests/final_checkpoint_registry.csv`.
- The paper reflects only completed, validated work (milestones 1--7). No planned work is
  presented as completed.
