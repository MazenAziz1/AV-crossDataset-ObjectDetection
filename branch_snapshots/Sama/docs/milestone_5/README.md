# Milestone 5 — Documentation

This directory contains the frozen evaluation protocol and in-domain results for
**Milestone 5** (KITTI training & in-domain evaluation + benchmarking).

Training and Kaggle infrastructure documentation lives in
[`docs/milestone_4/`](../milestone_4/README.md).

## Frozen Evaluation Protocol

| Document | Purpose | Status |
|----------|---------|--------|
| `evaluation_protocol.md` | COCO mAP metrics, operating point, scale metrics, KITTI DontCare suppression | FROZEN |

## Results

Final KITTI in-domain evaluation metrics, benchmarks, and comparison tables live under
`outputs/milestone_5/`:

- Metrics: `outputs/milestone_5/metrics/kitti_validation/{yolo,rtdetr,retinanet,faster_rcnn}_metrics.json`
- Benchmarks: `outputs/milestone_5/benchmarks/`
- Comparison tables: `outputs/milestone_5/figures/`

The locked checkpoints used for evaluation are recorded in
`outputs/milestone_4/manifests/final_checkpoint_registry.csv` (produced by Milestone 4
checkpoint locking).

Waymo cross-domain evaluation is deferred to Milestone 6.
